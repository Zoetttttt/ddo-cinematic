# ddov6

D Design Office 已确认的蓝色 DDO 开场版，独立、完整的网站文件夹。

- 网站内容与固定版本 `versions/2026-11-10-d` 一致。

## 单独部署

将 `ddov6` 作为网站根目录部署，保留文件夹内的目录结构。

- 构建命令：留空。
- 发布目录：`.`（本文件夹）。
- 从当前 GitHub 仓库部署时，项目基础目录设置为 `ddov6`。
- 已包含独立的 `netlify.toml`；无需数据库或 API 密钥。
