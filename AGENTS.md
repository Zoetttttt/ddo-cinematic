# Design edition preservation

The user requires every previous edition to keep a permanent access link.

- Dated directories under `versions/` are immutable snapshots. Never edit their HTML, scripts, styles, assets, or checksums unless the user explicitly requests editing that archived edition.
- The root may follow the latest requested revision. Before changing it, preserve the outgoing edition in a new dated directory and record the source commit and SHA-256 hashes.
- Keep the version index and existing snapshot URLs accessible. Verify archived file hashes before publishing.
- The user has explicitly removed mouse-follow movement from the homepage. Preserve its full-screen photo/video composition and current font unless asked to change them.
- The original cinematic website is the 5 November archive, before Services and the model introduction. Do not confuse it with the 9 November revision.
- Preserve the original 3.2-second photo dissolves and 32-second camera drift. Keep the requested order Sumi / Arctic / More Fun video / Dragon / Yebisu and use the supplied Dropbox originals.
- Pointer feedback means a gently expanding cursor and small elastic scaling on clickable controls; do not translate the homepage imagery with pointer movement.
- The opening has no visible skip button. A click, Enter, Space or Escape enters with geometric dissolution. Keep the dot-to-model reveal and the last-frame-to-header-logo handover continuous. Source model crops must exclude the presentation borders and centre the actual artwork without altering it.
